# todo-recoil
# 📝 ToDo List com React + Recoil

Projeto de lista de tarefas desenvolvido com React, Vite e Recoil para gerenciamento de estado global.

## 🚀 Tecnologias Utilizadas

- React
- Vite
- Recoil
- JavaScript
- CSS
